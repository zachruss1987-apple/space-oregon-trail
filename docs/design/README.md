## Pillars
1. **Scarcity you can see.** Every number on the status screen matters and the player can trace deaths back to choices.
2. **Wry, not mean.** Death is frequent and funny in the telling, never mocked in the moment of choice.
3. **The trail is a sequence of places.** Each waypoint has a name, a face, and a reason to stop.
4. **Thirty-minute runs.** A full journey takes 20–40 minutes; failure early is fast, so restarting is cheap.
5. **Retro honesty.** The game looks and sounds like it could have shipped on a 1985 disk, with modern conveniences (save, accessibility, seeds).
