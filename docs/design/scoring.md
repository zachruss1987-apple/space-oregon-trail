# Scoring

Computed on arrival at New Willamette. Mirrors the original's structure with renamed items.

| Line | Points |
|------|--------|
| Each surviving crew member | by final health: ≥ 75 → 500, ≥ 50 → 400, ≥ 25 → 300, else 200 |
| The ship | 50 |
| Each working ion drive | 4 |
| Each spare part (plate, pump, gyro) | 2 |
| Each EVA suit | 2 |
| Drone charges | 1 per 50 charges |
| Rations | 1 per 25 |
| Credits | 1 per 5 cr |
| **Subtotal × profession multiplier** | ×1 Executive, ×2 Engineer, ×3 Farmer |

Bonus (ours): arriving before flare season +200; zero crew deaths +300; both before multiplier.
