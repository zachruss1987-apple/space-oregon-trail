# M4 — Audiovisual polish

Goal: the game looks and sounds like a lost 1980s educational classic that happens to be set in space. Everything is generated in code; no binary assets.

Design inputs: `docs/design/art.md`, `audio.md`, `ui.md`.

## Graphics (src/gfx) — graphics
- Palette: 16-color Apple II-inspired palette plus CRT phosphor green for text. Defined once in `src/gfx/palette.ts`.
- Pixel-art sprite factory: sprites defined as string grids (`"..##.."`) in `src/gfx/sprites/*.ts`, rasterized to Phaser textures at boot. Ship (3 damage states), ion drive flare animation, stations (6 distinct), planets/landmarks (Mars, Ceres, Jupiter, Saturn, Titan, Kuiper Gate, Oort beacon, Proxima b), debris, drone, crew portraits (5 variants × healthy/sick), memorial beacon, tug ship.
- Travel scene art: multi-layer parallax starfield, foreground ship with drive animation, landmark approach (grows as distance shrinks), weather overlays (solar storm static, ion fog).
- Title screen hero image drawn procedurally; station exterior panel per station.
- CRT shader: scanlines, slight curvature/vignette, phosphor glow; toggle in Options; off by default on mobile.
- Pixel font: bitmap font generated from a glyph table (no web font download) with Phaser BitmapText.

## Sound (src/audio) — sound
- `Synth` module over Web Audio: square/triangle/noise channels, ADSR, arpeggios; a tiny tracker format (notes as strings) so music is data.
- Music: title theme (homage feel, original melody), travel loop (calm), danger sting, station theme, death dirge, arrival fanfare. All loop seamlessly.
- SFX: menu move/select, typewriter tick, purchase, drive hum, alarm, grapple fire, grab, collision, flare hit, beacon chime.
- Mute toggle, volume, and persistence of settings; audio starts on first user gesture per browser policy.

## Developer
- Wire sprites/fonts/music into all scenes; replace placeholder text with themed UI panels.
- Performance pass: texture atlas generated once, object pooling in mini-games.

## Tests
- Unit: sprite grid parser (dimensions, palette indices, errors), tracker parser (note/duration parsing), synth scheduling math.
- E2E: screenshots per scene committed as baselines under `tests/e2e/__screenshots__` with a tolerant pixel diff; CRT toggle changes rendering; audio context resumes after a click (assert state).

## Acceptance
- Every scene uses the palette and pixel font; no default Phaser text remains.
- Music and SFX play; settings persist.
- Bundle still loads in < 3 s on Pages (assert in e2e via navigation timing).
- Report in `docs/reports/M4.md` with a screenshot gallery.
