# M3 — Mini-games

Goal: the three moments the original made arcade-like (hunting, river fording, the Columbia rapids) become real-time mini-games. Each is a self-contained Phaser scene that reads/writes the sim via a small result object, so the sim stays headless.

Design inputs: `docs/design/minigames.md`.

## Salvage Run (hunting)
- Trigger: "Scan for salvage" from the travel menu; costs a day; needs ≥ 1 drone charge.
- Play: top-down drone in a drifting debris field, 30–45 s. Arrow keys / WASD / touch-drag to move, Space / tap to fire a grapple (uses a charge). Debris types yield rations, hull plates, coolant, gyros, or nothing; some chunks are hazards (tumbling, radioactive) that damage the drone.
- Carry limit: 100 units back to the ship, mirroring the 100 lb rule. Excess is wasted with a wry message.
- Deterministic under the game seed; mini-game RNG derived from the sim RNG so e2e can replay.

## Debris Field Threading (hazard "Thread it")
- Side-scrolling 20–30 s run through the field; dodge with up/down; collisions cost hull/supplies; density from the hazard's parameters. Finishing with zero hits grants a small bonus.

## Flare Belt Finale (Columbia River equivalent)
- Choice: ride the solar wind (mini-game) or pay the tug (credits). Ride: steer the ship between flare arcs for ~40 s; each hit damages crew/supplies; crashing ends the run.

## Shared
- `MiniGameResult` interface consumed by the sim (`applySalvageResult`, `applyThreadingResult`, `applyFlareResult`) with unit tests.
- Pause, skip-with-penalty (accessibility), and an auto-resolve option in settings that uses the sim's statistical outcome instead.
- Touch controls layer for mobile.

## Tests
- Unit: result application, carry-limit clamp, derived RNG determinism.
- E2E: each mini-game launches, accepts input, and returns a result to the travel scene (short, scripted runs with a fixed seed). Auto-resolve path tested too.

## Acceptance
- All three mini-games playable with keyboard and touch; results change supplies as specified.
- Frame rate stable (no long tasks > 50 ms in Playwright trace during a run).
- Report in `docs/reports/M3.md`.
