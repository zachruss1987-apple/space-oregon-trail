# M5 — Balance, accessibility, release

Goal: ship v1.0.0. The game is fair, tunable, saveable, accessible, and documented.

## Balance — developer, tester, designer
- `scripts/balance.mjs`: Monte Carlo harness running N seeded headless games per profession × launch window × policy (cautious, greedy, balanced). Outputs win rate, median days, death causes histogram, final score distribution as Markdown tables.
- Tune `src/content` numbers until targets hold: farmer (×3) hardest but winnable (~30%), executive easiest (~60%), average run 130–170 days, no single death cause > 35%.
- Difficulty select (Greenhorn / Spacer / Pathfinder) scaling event weights and prices.

## Features
- Save/load: autosave each day to `localStorage`, "Continue journey" on title; export/import save as JSON string.
- High scores: top ten with name, profession, score, date; shown from title menu; seeded with wry defaults.
- Options: CRT, music/SFX volume, text speed, auto-resolve mini-games, reduced motion, colorblind-safe palette variant, difficulty.
- "Learn about the Trail" screen: in-fiction guidebook (lore + practical tips), written by writer.

## Accessibility
- Full keyboard navigation with visible focus; number-key shortcuts for menus.
- Screen-reader support: a hidden live region mirrors the game log and menu options (Phaser canvas is opaque to AT).
- Reduced motion disables parallax/CRT; text contrast ≥ 4.5:1 across the palette.
- Pause anywhere; no time-critical input outside mini-games (which have auto-resolve).

## Release
- README: screenshots, play link, controls, how it was built (agent team, workflow, lessons), license (MIT), credits.
- `CHANGELOG.md`; version bump to 1.0.0; git tag; GitHub Release notes; Pages verified.
- Final report `docs/reports/FINAL.md`: what each role did, metrics (tests, coverage, tokens by role if available), what worked in the multi-agent workflow and what did not.

## Tests
- Unit: save/load round-trip including mid-event states; high score insertion/ordering; difficulty scaling.
- E2E: save then reload resumes; keyboard-only full run with a fixed seed; live region updates; options persist.
- Balance harness runs in CI (reduced N) and fails if win rates leave the target bands.

## Acceptance
- All above green; v1.0.0 live on Pages; owner can play end to end.
