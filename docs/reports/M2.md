## Lessons
- llama3.2 brainstorms yielded under 10% usable lines; the writer reports it is faster to write by hand. Keep the script for idea seeding only; do not plan content volume around it.
- Shared copy tables (`FALLBACK`/`PENDING`) let scene developers ship without waiting for the writer; the content test that forbids unresolved keys keeps the fallback from becoming permanent.
- Concurrent agents editing `ui.json` and `copy.ts` caused transient test failures; it worked because every agent scoped its commits, but a stricter rule (one writer at a time on each JSON file) would avoid noise.
- The e2e tester's `sceneTexts` helper (reads Phaser Text objects) made canvas assertions possible before the M5 live region.
