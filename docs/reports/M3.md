# M3 report — Mini-games (2026-10-25)

## Shipped
- Shared mini-game base: fixed 60 Hz step with accumulator, seeded RNG from `minigameSeed(seed, kind, day)`, instruction and result panels, pause (Esc), skip-with-penalty, touch layer (drag + tap, on-screen FIRE and pause), debug hooks `__PROXIMA__.minigame` with `finishNow()` / `finishWith()`, and `loadState()` under `?debug=1` for tests.
- Salvage Run (replaces the hunting auto-resolve): 40 s drone arena, grapple on charges, 9 debris types, tumbler and radioactive hazards, 100-unit tow with parts first.
- Debris Threading ("Thread it" becomes playable): 25 s side-scroll, rocks from the hazard's incident chance, hits map to the severity table with caps, clean-run bonus choice.
- Flare Belt finale: 45 s between flare arcs, 5 hits is a crash, clean ride earns "Rode the wind" +200.
- Sim: result intents with strict validation, skip variants, STATE_VERSION 3 with migration; the reference policy is byte-identical (50-seed snapshot fixture).
- Auto-resolve option (`autoResolveMiniGames`, `?minigames=auto`, Title hotkey M) keeps the statistical paths for accessibility and for deterministic e2e.

## Decisions
See `docs/design/decisions.md` 2026-10-24/25 M3 entries: refuse rather than clamp invalid results; Flare Belt keeps "Pay the tug"; auto-resolve cannot earn the clean-run bonus; e2e helpers default to auto-resolve with opt-in for mini-game specs.

## Lessons
- A 32-core machine let Playwright spawn 16 Chromium workers; cold boots then timed out and looked like flaky tests. Capping workers at 4 fixed it. Pin worker counts in config, not in agent instructions.
- Shared temporary copy tables (`PENDING`, `UNWRITTEN`) worked again, but two developers inventing table names in parallel is a smell; M4 consolidates to one `FALLBACK` plus the ui.json test.
- Letting the tester drive mini-games through `finishNow`/`finishWith`/`loadState` hooks made real-time scenes testable in seconds; design those hooks into the spec from the start.
