## Decisions
- 8×8 font at native scale instead of 6×8 at ×2 (kept 80-column layouts). Canvas renders at 1280×800 with 2× camera zoom so logical coordinates stay 640×400.
- CRT scanlines computed per device row in screen space to remove moire rings.
- Added `phosphorDim` (#38a838) because the forest palette color failed contrast on the panel fill.

## Lessons
- Give graphics and sound agents a preview scene and a checklist file (`asset-list.md`); both produced complete asset sets with no back-and-forth.
- Visual baselines are platform-specific; CI (Linux) needs its own set before the visual suite can gate merges.
- Temporary copy tables keep appearing; the content test that forbids unresolved keys is what keeps them temporary.
