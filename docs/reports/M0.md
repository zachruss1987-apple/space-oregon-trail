## Decisions
- Design numbers rebased by the designer after a rough simulation: 20/25/30 Mk/day thrust, ration health +2/0/−2, rations 0.30 cr, 15% daily event chance. Expected runs 140–155 days. Full detail in `docs/design/decisions.md`.
- `ui.md` menu labels are canonical; M1.md updated to match.
- Naive Farmer play wins ~1%: accepted for M1; M5 balance target is ~30%.
- events.json carries only id + text (writer's domain); weights, conditions, and effects live in `src/content/events.ts` (developer's domain) so the two can work in parallel.

## Lessons for M1
- Long multi-file heredocs through the shell get truncated; write big files with the file tool.
- Give agents an explicit "do not commit" rule and let the PM commit per card; it kept history clean.
- Spec-first paid off: the designer found that the original ration penalties killed everyone at Half rations before any code existed.
